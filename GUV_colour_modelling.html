Details

DESCRIPTION

Models photoreceptor responses and spectral sensitivities using theoretical visual pigment templates. Simulates UV and green photoreceptor activation curves under experimental LED illumination to estimate relative photoreceptor excitation and the effects of unequal absolute sensitivity.

INPUTS

None (self-contained theoretical model)

OUTPUTS

GUV_colour_modelling.html (rendered report with figures)

Introduction

In this analysis we simulate the detection of UV and green stimuli of different intensities by honeybee photoreceptors, and consequently their perceived spectral contrast and colour. Two distinct approaches are applied:

  1. Modelling of photoreceptor responses, based on their spectral sensitivity and intensity response curve.

  2. Default COC colour modelling using pavo.

Retina-level model

Photoreceptor Sensitivity

We define a function, StavengaSpline(), to generate visual pigment template curves for invertebrates. It supports \(A1\) pigment types and calculates the \(\alpha\)-, \(\beta\)-, and \(\gamma\)-absorption bands using modified log-normal models.

# Make a spline template for a visual pigment
StavengaSpline = function(spec_range = c(300, 700), #bounds of spectrum in nanometers
                          lambda_max,#peak sensitivity
                          a_type = 'a1'){#pigment type, only a1 available currently
  wlns =  seq(from = min(spec_range),
              to = max(spec_range), 
              length.out = 1e3) #
  # modified lognormal
  Mlognorm  = function(wl,l_max, a0, a1)
  {
    x = log10(wl/l_max)
    return(
      exp(-a0*x^2 *
            (1+a1*x+3*a1^2*x^2)
      )
    )
  }
  if(a_type == 'a1')
  {
    #alpha band
    a_band = Mlognorm(wl = wlns,
                      l_max = lambda_max, 
                      a0 = 380, 
                      a1 = 6.09)
    #beta band
    b_band = 0.29*Mlognorm(wl = wlns, 
                           l_max = 340, 
                           a0 = 247, 
                           a1 = 3.59)
    #gamma band
    g_band = 1.99*Mlognorm(wl = wlns, 
                           l_max = 276, 
                           a0 = 647, 
                           a1 = 23.4)
  }else
  {stop('a2 and a3 pigments not yet implemented')}
  # N.B. Stavenga normalises to max(a.band), I normalise to function max
  r_stav  = (a_band + b_band + g_band)/
    max(a_band + b_band + g_band)
  return(    smooth.spline(x = wlns,
                           y =  r_stav)    )
}#StavengaSpline <- function(spec.range, lambda.max)

Response Function

We model the photoreceptor response (in mV) to light intensity (photons/cm²/s) using a Naka-Rushton-like function. The parameters are based on honeybee photoreceptor recordings from Kolyfetis et al. (2025). See 1Data/250327_009_Apis_MainRetina_Kolyfetis2025.pdf. By default, we assume the semi-saturation point (\(k_{50}\)) is identical to that measured during those recordings. In a typical colour model, this is adjusted to the background average.

# Define a function for photoreceptor response
#params based on 250327_006 from Kolyfetis et al., 2025
PRresponse = function(
            quanta = 10^seq(from = 10, 
                            to  = 14, 
                            length.out = 21), #photons/cm2/s
            vmax = 50,#mV
            k50 = 0.03*1e14,#inflection point
            n = 1.07)#slope
  {
mV = (vmax*quanta^n)/ 
      (k50^n + quanta^n)
}
#this sets sensitivity in the following way
## rel_quanta = quanta/max(quanta)
## yy = mV/vmax
## sensitivity = k50*(yy/(1-yy))^(n^-1)

We establish parameters for the response peaks of honeybee photoreceptors (Menzel et al., 1986) and the emission peaks for the experimental ultraviolet and green LEDs, using a 20nm bandwidth range for the LED spectral distribution.

# Response peak for honeybee photoreceptors Menzel et al., 1986
lmax_u = 343
lmax_g = 543
# Emission peak for each LED
led_u = 365
led_g = 528
# A 20nm (uniform) band for each 
wlband = seq(from = -10, 
             to  = 10, 
             by = 0.1)

Sensitivity Curve Predictions

We predict the photoreceptors’ sensitivity curves across the insect-visible spectrum and specifically for the LED emission bands. We also calculate the integrated sensitivity for the green photoreceptor under green and UV LEDs to find its relative UV sensitivity (g_rel_u).

# Predict sensitivity curves across whole spectrum
u_photopig = predict(StavengaSpline(lambda_max = lmax_u))
g_photopig = predict(StavengaSpline(lambda_max = lmax_g))

# Specifically for the LEDs
#green photoreceptor
gPR_uLED = predict(StavengaSpline(lambda_max = lmax_g), x = led_u + wlband)
gPR_gLED = predict(StavengaSpline(lambda_max = lmax_g), x = led_g + wlband)
#UV photoreceptor
uPR_gLED = predict(StavengaSpline(lambda_max = lmax_u), x = led_g + wlband)
uPR_uLED = predict(StavengaSpline(lambda_max = lmax_u), x = led_u + wlband)

# integrated sensitivity
sens_gPR_uLED = integrate.xy(gPR_uLED)
sens_gPR_gLED = integrate.xy(gPR_gLED)
# spectral contrast (green-UV ratio)
g_rel_u = sens_gPR_uLED / sens_gPR_gLED

Colour Opponent Contrast Model

The colour opponent contrast model (Backhaus, 1991) estimates colour perception in a two dimensional space, in which the two axes represent linear combinations of the responses of the UV-, blue- and green-sensitive photoreceptors, scaled such that the Manhattan distances between colour loci indicate the perceptual distance, and the point \((0,0)\) corresponds to neutral grey.

The COC model simplifies the equation for photoreceptor responses from the Naka-Rushton (Naka & Rushton, 1966; Hill, 1910) equation, \[ R(P) = \frac{R_{\max} P^n}{P^n + K_{50}^n}\], to a hyperbolic equation, \[R(P_{relative}) = \frac{P_{relative}}{P_{relative} + 1}\], where \(P_{relative}\) is the integrated photon catch of a photoreceptor divided by the photon catch for the background, the slope \(n = 1\) (Backhaus & Menzel, 1987) is near constant around the inflection point at \(50\%\) saturation, and the \(50\%\) saturation parameter \(K_{50}\) adapts to the background intensity (Laughlin, 1989), which is set to \(P = 1\) for simplicity.

Linear opponency between the responses of these photoreceptors is coded by just two colour channels, \[A = -9.86 * R_\text{UV} + 7.70 * R_\text{blue} + 2.16 * R_\text{green}\] \[B = -5.17 * R_\text{UV} + 20.25 * R_\text{blue} - 15.08 * R_\text{green}\],
the weightings having been derived experimentally (Backhaus et al., 1987). Perceived colour distances are the sum of differences in both \(A\) & \(B\) (city-block or Manhattan distance).

Set up functions

First set up a function that calculates the COC trajectories of monochromatic lights across a given range of relative intensities (measured relative to the background). We will also try to do this using pavo default functions, although these do not work in precisely the same way.

get_pavo_trajectories = function(test_wls, #wavelengths of monochromatic light
                                 intensity, #relative intensities
                                 background = rep(x = 1.0/sum(pavo::sensdata(visual = "apis")$wl<650), #adds to 1.0 at bee-visible wavelengths
                        times = length(pavo::sensdata(visual = "apis")$wl))
  ){
  # Establish the standard 300 to 700 nm wavelength backbone 
  wl_backbone = pavo::sensdata(visual = "apis")$wl
  
  # Build the master pavo rspec matrix
  pavo_matrix = data.frame(wl = wl_backbone)
  
    for (target_wl in test_wls) {
    for (i in 1:length(intensity)) {
      col_name = paste0("WL_", target_wl, "_Mult_", i) # name to easily retrieve wavelength
      pavo_matrix[[col_name]] = ifelse(wl_backbone == target_wl,
                                        yes =  intensity[i],
                                        no =  0)
    }
  }
  pavo_rspec = suppressMessages(as.rspec(pavo_matrix))
  
  # Run the native pavo vismodel pipeline
  pavo_vis = vismodel(
    rspecdata  = pavo_rspec,
    visual     = "apis",
    qcatch     = "Ei",           
    illum      = "ideal",        
    bkg        = background,
    vonkries   = TRUE,           # Active automatic normalization
    relative   = FALSE           
  )
  
  # 5. Project directly into Color Opponent Coding (COC) Space
  pavo_coc = colspace(vismodeldata = pavo_vis, 
                      space = "coc")
  
  # Build the matching metadata layout to map vectors back together
  metadata = expand.grid(
    intensity_step = 1:length(intensity), 
    wavelength     = test_wls
  )
  
  # Package everything into a clean data frame matching the Backhaus layout exactly
  trajectory_data = data.frame(
    wavelength = as.character(metadata$wavelength),
    intensity  = intensity[metadata$intensity_step],
    x          = pavo_coc$x,
    y          = pavo_coc$y,
    chroma = with(pavo_coc, abs(x) + abs(y)), #absolute Manhattan distance from neutral grey 
    uv = pavo_vis$s, #save the photoreceptor responses
    bl = pavo_vis$m,
    gr = pavo_vis$l
  )
  
  return(trajectory_data)
}

# plotting function
plot_coc_trajectories = function(trajectory_data, #data from get_backhaus_trajectories or get_pavo_trajectories
                                  main_title = "Intensity-Dependent Colour Trajectories", 
                                  line_col = c("344" = "orchid4", 
                                                  "416" = "blue3", 
                                                  "494" = "cyan3", 
                                                  "532" = "darkgreen"), #needs to be named like trajectory_data$wavelength
                                 ref_point = 100 # indicate 1st point >100x background
                                 ) {
  
  # 1dummy data frame structure for pavo canvas grid
  dummy_pavo = data.frame(s = 0, 
                          m = 0, 
                          l = 0, 
                          x = c(-12, 12), 
                          y = c(-12, 12))
  class(dummy_pavo) = c("colspace", "coc", "data.frame")
  
  # Open colour opponent contrast plot
  pavo::cocplot(dummy_pavo, 
                main = main_title, 
                col = "transparent")
  
  # Identify wavelengths
  unique_wls = unique(trajectory_data$wavelength)
  
  # Map over each wavelength vector to draw its expanding trajectory line
  for (wl_idx in unique_wls) {
    # Extract specific line color for this wavelength track
    current_col = if (wl_idx %in% names(line_col)){ line_col[wl_idx] }else{ "black" }
    
    
    # Draw continuous expanding color vector path
    with(trajectory_data[trajectory_data$wavelength == wl_idx, ],
         {
    lines(x = x, 
          y = y, 
          col = current_col, 
          lwd = 3.5)
    # 1st point 10x brighter than background
    points(x = x[which(intensity > ref_point)][1],
           y = y[which(intensity > ref_point)][1], 
           col = "black", 
           pch = 21, 
           bg = current_col, 
           cex = 1.3)
    # Indicate final position at maximum intensity
    points(x = x[length(x)],
           y = y[length(y)], 
           col = "gray75", 
           pch = 21, 
           bg = current_col, 
           cex = 1.3,
           lwd = 3)
         }
    )
    
  }
  
}

Plot_COC_equal = function(x = 0,
                          y = 0,
                          threshold = 1.83,
                          ...)
{
  xx = c(x - threshold, # left corner
         0, # top
         x + threshold, #right corner
         0, # bottom
         x - threshold) #left corner
  yy = c(0,
         y + threshold,
         0,
         y - threshold,
         0)
  polygon(x = xx,
          y = yy,
          ...)
}

Simulate Bezold-Brücke Effect

In some experiments, honeybees interpreted coloured stimuli with the same reflectance spectrum as different colours depending on their brightness, although brightness differences did not play a role in stimulus discrimination. In the colour opponent contrast (COC) model (Backhaus, 1991, 1992), these shifts in perceived colour, known as the Bezold-Brücke effect in human colour vision (Purdy, 1931), could be predicted from the non-linear responses of photoreceptors to increasing brightness.

This effect can be demonstrated well at 344 nm (UV \(\lambda_\max\)), 416 nm and 494 nm (equal UV-B and B-G sensitivity) 532 nm (high G sensitivity).

Here we do indeed observe a drop in UV saturation above \(100 \times\) background. At higher intensities, both the UV and green LEDs approach the “blue” quadrant in the positive A and B directions as the responses of the other photoreceptors (blue and green for UV; blue and UV for green) grow more rapidly than the saturated target receptor. These trajectories curve back towards the \((0,0)\) achromatic (neutral grey) point without crossing the A or B axes, as all photoreceptors approach saturation. This occurs at lower intensities for the UV LED, which also stimulates the \(\beta\) peak of the other two receptors.

In the light adapted situation, the Bezold-Brücke effect is more limited, but still occurs for the brighter stimuli. The dim stimuli are dimmer than the background, resulting in activation of only their target photoreceptor (UV \(A<0\), green \(B<0\)) but very little activation of the blue-sensitive photoreceptor (\(A \& B >0\)).
